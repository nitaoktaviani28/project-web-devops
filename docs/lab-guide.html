4. Langkah-langkah Lab

4.1 Fork Repository

Info: Peserta cukup fork repository, tidak perlu buat dari awal.
  1. Buka https://github.com/nitaoktaviani28/project-web-devops
  2. Klik tombol Fork di kanan atas
  3. Clone ke lokal: 
    git clone https://github.com/USERNAME_ANDA/project-web-devops.git
cd project-web-devops

4.2 Install Tools di PC

Buka CMD sebagai Administrator:

choco install terraform awscli git -y

Setelah install, buka CMD baru dan verifikasi:

terraform --version
aws --version
git --version
Note: Jika belum punya Chocolatey, install dari https://chocolatey.org/install

4.3 Konfigurasi AWS CLI

aws configure

Masukkan:

PromptIsi
AWS Access Key IDAccess Key dari IAM Console
AWS Secret Access KeySecret Key dari IAM Console
Default region nameap-southeast-1
Default output formatjson

Verifikasi:

aws sts get-caller-identity

4.4 Generate SSH Key

ssh-keygen -t ed25519 -f %USERPROFILE%\.ssh\vm-demo-key -N "" -C "vm-demo"

Lihat public key:

type %USERPROFILE%\.ssh\vm-demo-key.pub

4.5 Konfigurasi Terraform

Edit file terraform/terraform.tfvars:

name               = "vm-demo"
vpc_cidr           = "10.0.0.0/16"
public_subnet_cidr = "10.0.1.0/24"
availability_zone  = "ap-southeast-1a"
instance_type      = "t3.medium"

tags = {}

ssh_public_key = "ssh-ed25519 AAAA... vm-demo"
Penting: Ganti ssh_public_key dengan output dari langkah 4.4

4.6 Provision Infrastructure dengan Terraform

cd terraform
terraform init
terraform plan
terraform apply -auto-approve

Output yang penting:

instance_public_ip = "x.x.x.x"
Hasil: VPC, Subnet, IGW, Route Table, Security Group (port 22, 80, 30080), dan EC2 instance berhasil dibuat.

4.7 SSH ke EC2 dan Install Docker + K3d

SSH ke VM (dari CMD):

ssh -i %USERPROFILE%\.ssh\vm-demo-key ubuntu@<IP_VM>

Setelah masuk VM, jalankan script install:

curl -fsSL https://get.docker.com | sh && \
sudo usermod -aG docker $USER && \
curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash && \
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl" && \
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl && \
rm kubectl && \
sudo systemctl enable docker && \
sudo systemctl start docker && \
sudo k3d cluster create mycluster --port "30080:30080@server:0" --agents 2 && \
mkdir -p ~/.kube && \
sudo k3d kubeconfig get mycluster > ~/.kube/config && \
chmod 600 ~/.kube/config && \
echo 'export KUBECONFIG=/home/ubuntu/.kube/config' >> ~/.bashrc && \
export KUBECONFIG=/home/ubuntu/.kube/config && \
kubectl get nodes

Expected output:

NAME                      STATUS   ROLES                  AGE   VERSION
k3d-mycluster-server-0    Ready    control-plane,master   1m    v1.35.x
k3d-mycluster-agent-0     Ready    <none>                 1m    v1.35.x
k3d-mycluster-agent-1     Ready    <none>                 1m    v1.35.x

4.8 Setup GitHub Secrets

Di repository GitHub: Settings > Secrets and variables > Actions > New repository secret

Secret NameValue
EC2_HOSTIP publik EC2 (dari output Terraform)
EC2_SSH_KEYIsi file private key vm-demo-key (termasuk BEGIN/END)
DOCKERHUB_USERNAMEUsername Docker Hub kamu
DOCKERHUB_TOKENAccess Token dari Docker Hub (hub.docker.com/settings/security)

4.9 Update Image Name di Kubernetes Manifest

Edit k8s/deployment.yaml, ganti image name sesuai Docker Hub username kamu:

image: USERNAME_DOCKERHUB/devops-demo-app:latest

4.10 Push dan Trigger CI/CD

git add .
git commit -m "setup: configure secrets and deploy"
git push
Hasil: GitHub Actions otomatis:
  1. Build Docker image dari app/Dockerfile
  2. Push image ke Docker Hub dengan tag SHA commit
  3. SSH ke EC2 dan deploy ke K3d cluster

4.11 Verifikasi Deployment

Buka browser:

http://<IP_VM>:30080

Atau dari VM:

kubectl get pods
kubectl get svc

6. Cleanup (Hapus Semua Resource)

Setelah selesai lab, hapus semua resource AWS agar tidak kena charge:

cd terraform
terraform destroy -auto-approve
Penting: Selalu destroy resource setelah selesai lab untuk menghindari biaya.
